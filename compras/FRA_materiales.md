# Control de Tono — S12 — Lista de materiales (FRA)

## Descripción del proyecto

Control de Tono es un proyecto que tiene como objetivo introducir de manera técnica conceptos transversales a la ingeniería electrónica con un enfoque didáctico para estudiantes de primeros semestres de ingeniería electrónica. Para esto, se propone como caso de estudio los sistemas de audio para a través de estos descubrir y aprender a interpretar herramientas como diagramas de bode o filtros.

A nivel metodológico se propone el diseño de un Analizador de Respuesta de Frecuencia (FRA - Frequency Response Analyzer) para generar visualizaciones de las características del audio a lo largo del curso con la capacidad de permitir el análisis en todo el rango audible (20Hz-20KHz).

### Arquitectura de hardware

- **Cadena de entrada**: jack 1/4" mono → buffer de alta impedancia (~1MΩ) con pot de ganancia → switch de modo (guitarra / ruido blanco) → ADC₁ (96 kSps, I²S)
- **Slot DUT**: conector modular de 4 terminales para la red bajo prueba
- **Cadena de salida**: ADC₂ (96 kSps, sincronizado) → buffer de salida + driver de parlante → jack 1/4" mono
- **Microcontrolador**: captura ambos ADCs vía I²S, calcula FFT de entrada/salida, calcula H(f) = FFT(salida)/FFT(entrada), controla switch de modo, footswitch y 6 botones programables, envía datos al PC vía USB
- **Generador de ruido blanco**: señal de excitación para conocer respuesta en frecuencia y diagrama de bode (espectro plano, permite medir todo el rango en una sola captura de 500 ms a 1 s)
